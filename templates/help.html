🔒 How SMTP App Passwords Work

Major email providers require an App Password rather than your personal login password for automated email sending.

Gmail & Google Workspace

1. Enable 2-Step Verification on your Google Account.
2. Navigate to Google Account > Security > App Passwords.
3. Generate a 16-character App Password for "Mail". Use port 465 with SSL.

Microsoft Outlook / Office 365

Use SMTP Host smtp.office365.com, Port 587, Security STARTTLS. If 2FA is enabled, generate an App Password in your Microsoft Account Security settings.

Yahoo Mail

Use SMTP Host smtp.mail.yahoo.com, Port 465, Security SSL. Generate an App Password under Yahoo Account Security.

⚡ Personalization Tag Syntax

Use {{ variable_name }} in your Subject or Body. Any CSV column header will automatically be converted to a placeholder tag.

Example: If your CSV has headers first_name, company, role, you can use: 

Hi {{ first_name }},

I noticed your position as {{ role }} at {{ company }}.
